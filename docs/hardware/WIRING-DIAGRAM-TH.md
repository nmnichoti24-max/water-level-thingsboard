# ผังการต่อสาย ESP32-S3 + Ultrasonic Sensor (WaterGuard Pro)

> **สถานะ: รอยืนยันจากภาพถ่าย** ผู้ใช้ยืนยันแล้วว่าใช้บอร์ด ESP32-S3 แบบมี USB-C 2 ช่อง (COM / USB) ส่วนเซนเซอร์สีน้ำเงินคาดว่าเป็น JSN-SR04T หรือ AJ-SR04M แต่ **ยังไม่ยืนยันรุ่น** ห้ามจ่ายไฟให้วงจรเซนเซอร์และห้ามตั้ง `WIRING_VERIFIED 1` จนกว่าจะตรวจภาพถ่ายทั้งสองด้านของบอร์ดเซนเซอร์และบอร์ด ESP32-S3 ตามหัวข้อ "รายการตรวจก่อนจ่ายไฟ"

ข้อมูลที่ตรวจแล้วจากเครื่องนี้ (24 พ.ย. 2026): Windows เห็นบอร์ดที่ **COM3** ผ่านชิป USB-UART **WCH CH343** (`USB\VID_1A86&PID_55D3`) ซึ่งเป็นพอร์ตฝั่ง "COM" ของบอร์ดสองพอร์ต

## ขาที่ใช้ (ตามไฟล์ `firmware/WaterGuard_ESP32S3/config.h`)

| สายเซนเซอร์ | ต่อไปที่ ESP32-S3 | แรงดัน | หมายเหตุ |
| --- | --- | --- | --- |
| VCC | ขา **5V** (บางบอร์ดพิมพ์ `5V`, `5Vin` หรือ `VBUS`) | 5 V | JSN-SR04T / AJ-SR04M ใช้ไฟ 5 V ได้ระยะดีที่สุด **วัดขา 5V ด้วยมัลติมิเตอร์ก่อน** ต้องได้ประมาณ 4.7–5.2 V ขณะเสียบ USB (บางบอร์ดต้องบัดกรีจัมเปอร์ `IN-OUT` ก่อนขา 5V จึงจ่ายไฟออก) |
| GND | ขา **GND** | 0 V | ใช้กราวด์ร่วมกันเสมอ |
| TRIG | **GPIO5** | 3.3 V (ESP32-S3 เป็นฝ่ายส่ง) | ส่งตรงได้ เซนเซอร์ตระกูลนี้ส่วนใหญ่รับ 3.3 V เป็น HIGH ถ้าอ่านได้ `NO_ECHO` ตลอดทั้งที่ต่อถูก ให้ใช้ Level Shifter (เช่น BSS138) ที่ TRIG |
| ECHO | ผ่าน**วงจรแบ่งแรงดัน**ก่อนเข้า **GPIO6** | เซนเซอร์ส่ง 5 V → ลดเหลือ ~3.3 V | **ห้ามต่อ ECHO 5 V เข้า GPIO โดยตรง** GPIO ของ ESP32-S3 ทนสูงสุด 3.3 V |

ทำไมเลือก GPIO5 / GPIO6: เป็นขา GPIO ทั่วไปของ ESP32-S3 ไม่ใช่ขา Strapping (0, 3, 45, 46), ไม่ใช่ USB (19, 20), ไม่ใช่ Flash/PSRAM ของโมดูล N16R8 (26–37), ไม่ใช่ UART0 ที่ต่อกับ CH343 (43, 44) และไม่ใช่ RGB LED บนบอร์ด (48 ในบอร์ดส่วนใหญ่) **ให้ใช้ป้ายพิมพ์บนบอร์ดจริงว่า `5` และ `6` อยู่ตำแหน่งไหน** ห้ามนับตำแหน่ง Header เอาเอง ถ้าเปลี่ยนขา ให้แก้ `PIN_TRIG` / `PIN_ECHO` ใน config.h แล้วแก้ตารางนี้ด้วย

## วงจรแบ่งแรงดันที่ ECHO

```
 Sensor ECHO ──[ R1 = 1 kΩ ]──┬──────────► ESP32-S3 GPIO6
                              │
                         [ R2 = 2 kΩ ]
                              │
 Sensor GND ──────────────────┴──────────► ESP32-S3 GND

 Vout = 5 V × R2 / (R1 + R2) = 5 × 2 / 3 ≈ 3.33 V
```

ค่าที่ใช้แทนได้: R1 = 10 kΩ, R2 = 20 kΩ (≈3.33 V) หรือ R1 = 2.2 kΩ, R2 = 3.3 kΩ (≈3.0 V) ถ้าไม่มี 2 kΩ ใช้ 1 kΩ สองตัวต่ออนุกรมเป็น R2 ได้

**ข้อควรระวัง:** วงจรแบ่งแรงดันนี้ออกแบบสำหรับเซนเซอร์ที่ใช้ไฟ **5 V** เท่านั้น ถ้าเปลี่ยนไปจ่ายไฟเซนเซอร์ 3.3 V (เฉพาะรุ่นที่รองรับ เช่น JSN-SR04T v3, AJ-SR04M, HC-SR04P) ECHO จะเป็น 3.3 V อยู่แล้ว ให้ต่อ ECHO เข้า GPIO6 ตรงโดย**ไม่ใช้**ตัวแบ่ง เพราะ 3.3 V × 2/3 = 2.2 V ต่ำกว่าระดับ HIGH ขั้นต่ำของ ESP32-S3 (≈2.48 V)

## ผังรวม

```
 ESP32-S3 Dev Board                         Ultrasonic module (JSN-SR04T / AJ-SR04M — รอยืนยัน)
 (USB-C "COM" → คอมพิวเตอร์)
 ┌───────────┐                              ┌───────────┐
 │ 5V        ●──────────────────────────────● VCC       │
 │ GND       ●──────────────┬───────────────● GND       │
 │ GPIO5     ●──────────────│───────────────● TRIG      │
 │ GPIO6     ●───────┬      │        ┌──────● ECHO      │
 └───────────┘       │      │        │      └─────┬─────┘
                     │   [R2 2kΩ]  [R1 1kΩ]       │ สายโพรบกันน้ำ
                     │      │        │           (◉) หัววัด หันลงผิวน้ำ
                     └──────┴────────┘
                    node: GPIO6 ← จุดต่อระหว่าง R1 กับ R2, ปลายอีกด้านของ R2 ลง GND
```

อ่านแบบรายการ:

1. ESP32-S3 `5V` → เซนเซอร์ `VCC`
2. ESP32-S3 `GND` → เซนเซอร์ `GND` และปลายล่างของ R2
3. ESP32-S3 `GPIO5` → เซนเซอร์ `TRIG`
4. เซนเซอร์ `ECHO` → R1 (1 kΩ) → จุดต่อ (node)
5. จุดต่อ (node) → ESP32-S3 `GPIO6`
6. จุดต่อ (node) → R2 (2 kΩ) → `GND`

## OLED และ LED สถานะ

| อุปกรณ์ | ขาอุปกรณ์ | ต่อไปที่ ESP32-S3 | หมายเหตุ |
| --- | --- | --- | --- |
| OLED SSD1306 128x64 (I2C 0x3C) | VCC | **3V3** | ใช้ 3.3 V เพื่อให้ pull-up ของ SDA/SCL บนโมดูลเป็น 3.3 V |
| | GND | GND | |
| | SDA | **GPIO9** | |
| | SCL | **GPIO8** | |
| LED เขียว (NORMAL) | ขายาว (+) | **GPIO18** ผ่านตัวต้านทาน 220–330 Ω | ขาสั้น (−) ลง GND |
| LED เหลือง (WARNING) | ขายาว (+) | **GPIO17** ผ่านตัวต้านทาน 220–330 Ω | ขาสั้น (−) ลง GND |
| LED แดง (DANGER / กะพริบ = SENSOR ERROR) | ขายาว (+) | **GPIO16** ผ่านตัวต้านทาน 220–330 Ω | ขาสั้น (−) ลง GND |

ถ้า OLED ไม่ตอบที่ 0x3C เฟิร์มแวร์จะพิมพ์ `OLED: not found` แล้ววัดค่าและส่ง ThingsBoard ต่อตามปกติ
LED ภายนอกเปิดใช้เมื่อตั้ง `EXTERNAL_LEDS_VERIFIED 1` หลังตรวจว่าทุกดวงมีตัวต้านทานอนุกรมแล้วเท่านั้น

## โหมดของบอร์ดเซนเซอร์

เฟิร์มแวร์ใช้โหมด TRIG/ECHO แบบเดียวกับ HC-SR04 (ส่งพัลส์ TRIG 20 µs แล้ววัดความกว้างพัลส์ ECHO)

- JSN-SR04T: ตำแหน่ง **R27 ต้องว่าง** (ไม่มีตัวต้านทาน) = โหมด 1
- AJ-SR04M: ตำแหน่ง **R19 ต้องว่าง** = โหมด 1
- ถ้ามีตัวต้านทานบัดกรีที่ตำแหน่งเหล่านี้ บอร์ดอาจอยู่ในโหมด UART หรือโหมดอัตโนมัติ ซึ่งเฟิร์มแวร์นี้ไม่รองรับ ให้ส่งภาพมาตรวจก่อน

## ระยะใช้งาน

| รุ่น | ระยะอับ (Blind zone) | ระยะสูงสุดโดยประมาณ |
| --- | --- | --- |
| JSN-SR04T | ~20–25 cm | ~450–600 cm |
| AJ-SR04M | ~20 cm | ~450–600 cm |
| HC-SR04 | ~2 cm | ~400 cm |

ค่าเริ่มต้น `MIN_DISTANCE_CM 20`, `SENSOR_TO_FULL_CM 25` (เต็ม) และ `SENSOR_TO_BOTTOM_CM 100` (ว่าง) ตั้งไว้ให้ผิวน้ำตอนเต็มถังยังอยู่นอกระยะอับ (25 cm อยู่ขอบบนของระยะอับ JSN-SR04T ถ้าน้ำใกล้เต็มแล้วอ่านค่าแกว่ง ให้ติดตั้งหัววัดสูงขึ้นแล้วปรับค่าใหม่) ห้ามติดตั้งหัววัดให้ผิวน้ำเข้าใกล้กว่าระยะอับ เพราะค่าที่อ่านได้จะไม่ถูกต้อง

## รายการตรวจก่อนจ่ายไฟ (ต้องผ่านทุกข้อ)

1. ส่งภาพหน้า–หลังของบอร์ดเซนเซอร์ เห็นชื่อรุ่นและตำแหน่ง R27/R19 ชัดเจน
2. ส่งภาพบอร์ด ESP32-S3 ที่เห็นป้ายพิมพ์ของขา 5V, GND, 5, 6, 8, 9, 16, 17, 18
3. ถอด USB ออกก่อนต่อสายทุกครั้ง
4. วัดความต้านทานตัวแบ่งแรงดัน: R1 ≈ 1 kΩ, R2 ≈ 2 kΩ
5. เสียบ USB โดย**ยังไม่ต่อสายเซนเซอร์** วัดขา 5V เทียบ GND ต้องได้ ~5 V
6. ตรวจว่าสาย ECHO ไม่ได้ต่อตรงเข้า GPIO6 โดยไม่ผ่านตัวแบ่ง
7. ตรวจว่าไม่มีสาย 5V แตะขา GPIO ใดๆ
8. เมื่อผ่านทั้งหมดแล้ว จึงตั้ง `#define WIRING_VERIFIED 1` ใน config.h และ Upload ตาม [ARDUINO-UPLOAD-GUIDE-TH.md](ARDUINO-UPLOAD-GUIDE-TH.md)
